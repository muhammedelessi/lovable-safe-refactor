# Source and Maintenance Notes

This skill is an original workflow for safely refactoring Lovable-built projects. It intentionally avoids copying a third-party refactoring skill as an authority.

Maintain these principles against current primary documentation when framework behavior matters:

- Lovable documentation for project, GitHub, Supabase, security, and workflow behavior
- React documentation for component/effect/state semantics
- TypeScript documentation for type-system behavior
- Supabase documentation and official agent skills for database, Auth, RLS, and API behavior
- OWASP guidance for security-sensitive refactors

Do not freeze volatile framework details into the workflow when the current repository or official documentation can answer them more reliably.
